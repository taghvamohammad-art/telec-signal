## موتور داده چه می‌کند

- هر روز ۱۰۰ ارز برتر فیوچرز بایننس (بر اساس حجم) را که در فیوچرز ال‌بانک هم هستند پیدا می‌کند و در `universe_snapshots` ذخیره می‌کند.
- از بین آن‌ها ۴۰ ارز (قابل تنظیم) را برای تحلیل کامل انتخاب می‌کند: ۷۰٪ نقدشوندگی + ۳۰٪ نوسان، BTC و ETH همیشه.
- کندل‌های ۱۵ دقیقه، ۱ ساعت، ۴ ساعت و روزانه را از ۱۲۰ روز قبل پر می‌کند و بعد به‌صورت زنده از WebSocket می‌گیرد.
- **فقط کندل بسته‌شده** ذخیره می‌شود. کندل ناقص، تکراری، نامرتب یا با قیمت نامعتبر رد و در `data_issues` ثبت می‌شود.
- هر ساعت شکاف‌های داده را پیدا و از REST پر می‌کند.
- هر ۵ دقیقه Funding Rate و Open Interest را ذخیره می‌کند.
- اگر WebSocket ساکت شد یا کندل جدید نرسید، به تلگرام مدیر هشدار می‌دهد.

## موتور تحلیل چه می‌کند

- ۲۵ ثانیه بعد از بسته شدن هر کندل ۱۵ دقیقه، ارزهای فهرست تحلیل را بررسی می‌کند (سرویس `telec-analysis`).
- وضعیت بازار ۱ساعته: روندی صعودی/نزولی، رنج، فشرده یا آشفته؛ جهت کلی از ۴ساعته.
- نسخه ۲٫۱ (بعد از اولین بک‌تست):
  - سبک‌های پایه (می‌توانند سیگنال بسازند): پولبک روندی، شکست محدوده فشرده، مومنتوم ۴ساعته (شکست سقف/کف ۵۵ کندل ۴ساعته در جهت روند روزانه)
  - تأییدکننده: شکار نقدینگی، VWAP و حجم
  - فقط نمایشی (بی‌اثر در تصمیم، چون در بک‌تست ضررده بودند): واگرایی RSI، برگشت به میانگین
- قواعد: یک سبک پایه با قدرت ۰٫۶+ و در مجموع حداقل دو سبک هم‌جهت، بدون سبک پایه مخالف، امتیاز ۷۰+، حد ضرر بین ۰٫۵ تا ۳ ATR ساعتی، بدون معامله در بازار رنج و آشفته، ریسک ثابت ۱٪.
- فیلتر بازار: آشفتگی یا حرکت شدید بیت‌کوین سیگنال را متوقف می‌کند؛ روند مخالف بیت‌کوین و فاندینگ یک‌طرفه امتیاز را کم می‌کند.
- تطبیق با ال‌بانک: قبل از ثبت هر سیگنال، قرارداد ال‌بانک، اختلاف قیمت (حداکثر ۰٫۵٪)، اسپرد (حداکثر ۰٫۲٪) و عمق بازار (حداقل ۵۰۰۰ دلار در ۰٫۵٪ اطراف قیمت) بررسی می‌شود و سطوح به قیمت ال‌بانک تبدیل می‌شوند (با در نظر گرفتن تفاوت 1000PEPE و PEPE). قابل تنظیم با `LBANK_MAX_DIFF_PCT`، `LBANK_MAX_SPREAD_PCT`، `LBANK_MIN_DEPTH_USDT`.
- خروجی در جدول `signal_candidates`؛ آخرین وضعیت هر ارز در `analysis_state`. ارسال به تلگرام در مرحله ۴.

```bash
.venv/bin/python scripts/analyze_now.py            # تحلیل همین لحظه همه ارزها (بدون ذخیره)
.venv/bin/python scripts/analyze_now.py SOLUSDT    # جزئیات یک ارز
journalctl -u telec-analysis -f
```

## پنل وب و ترید مجازی

- آدرس: `https://signal.telec.shop` (سرویس `telec-web` پشت Nginx با گواهی رایگان Let's Encrypt).
- نمودار: کندل‌ها، فلش سیگنال‌ها، خط‌های ورود/حد ضرر/TP، و «نردبان ریسک» هر سیگنال.
- ترید مجازی: هر کاربر سرمایه آزمایشی خودش را دارد. هر سیگنال با قیمت باز شدن کندل ۱۵ دقیقه بعد وارد می‌شود؛ ریسک ۰٫۵ تا ۱٫۵٪ بر اساس امتیاز؛ اهرم کمترین مقدار کافی تا ۲۰x به‌شرط فاصله امن لیکوئید؛ نصف پوزیشن در TP1 و انتقال حد ضرر به ورود؛ اگر یک کندل هم حد ضرر و هم هدف را لمس کند، ضرر حساب می‌شود؛ کارمزد ۰٫۰۶٪ و فاندینگ واقعی کسر می‌شود.

کاربران:

```bash
sudo -u telec .venv/bin/python scripts/manage_users.py add admin --admin
sudo -u telec .venv/bin/python scripts/manage_users.py add ali
sudo -u telec .venv/bin/python scripts/manage_users.py list
sudo -u telec .venv/bin/python scripts/manage_users.py passwd ali
sudo -u telec .venv/bin/python scripts/manage_users.py disable ali
```

## بات تلگرام

۱. در تلگرام به `@BotFather` پیام بدهید، `/newbot` را بزنید و توکن را بگیرید.
۲. در `/opt/telec-signal/.env` بنویسید: `TELEGRAM_BOT_TOKEN=...` و سرویس را ری‌استارت کنید: `sudo systemctl restart telec-bot`.
۳. هر کاربر در سایت دکمه «تلگرام» را می‌زند و با یک لینک یک‌بارمصرف حسابش را وصل می‌کند.

پیام‌ها: سیگنال جدید با قیمت‌های ال‌بانک، رسیدن به TP1 (نصف را ببندید و حد ضرر را به ورود ببرید)، هدف نهایی، حد ضرر، سربه‌سر، و باطل شدن قبل از ورود. حداکثر ۱۰ سیگنال در ۲۴ ساعت (`DAILY_SIGNAL_CAP`). فوروارد پیام‌ها قفل است. دستورهای بات: `/status`، `/on`، `/off`.

هر سیگنال جدا از حساب‌های ترید مجازی، تا پایان پیگیری می‌شود و نتیجه‌اش بر حسب R ذخیره می‌شود (`signal_candidates.result_r`)؛ این سابقه واقعی سیستم است.

## بک‌تست

```bash
cd /opt/telec-signal
sudo -u telec .venv/bin/python scripts/extend_history.py --days 400     # یک بار: تاریخچه طولانی‌تر
sudo -u telec .venv/bin/python -m app.backtest.run --days 400
```

ردیف «دیده‌نشده» در گزارش، دوره قبل از ۳۰ ژوئیه ۲۰۲۶ است که هنگام انتخاب قواعد نسخه ۲٫۱ به آن نگاه نشده بود؛ معتبرترین بخش گزارش است.

همان قواعد زنده، کندل به کندل روی داده‌های ذخیره‌شده اجرا می‌شود (تستی تضمین می‌کند تصمیم بک‌تست و تصمیم زنده در هر لحظه یکی است). تاریخچه فاندینگ از بایننس گرفته می‌شود. نتیجه در تب «بک‌تست» پنل: نتیجه هر سیگنال بر حسب R، حساب آزمایشی با قواعد ترید مجازی، داخل/خارج نمونه، و تفکیک سبک، امتیاز، وضعیت بازار و جهت. روی سرور ۲ هسته‌ای حدود ۱۰ دقیقه طول می‌کشد.

## نصب روی سرور (Ubuntu 24.04)

```bash
sudo git clone https://github.com/taghvamohammad-art/telec-signal /opt/telec-signal
cd /opt/telec-signal
sudo bash deploy/install.sh
```

چون مخزن خصوصی است، `git clone` نام کاربری و رمز می‌خواهد: نام کاربری گیت‌هاب و به‌جای رمز یک **Fine-grained token** با دسترسی فقط‌خواندنی (Contents: Read) به همین مخزن (GitHub → Settings → Developer settings → Personal access tokens).

اسکریپت نصب این کارها را می‌کند: PostgreSQL و TimescaleDB، Swap دو گیگی (برای سرور کم‌رم)، ساخت دیتابیس و فایل `.env`، محیط پایتون، اجرای تست‌ها، تست اتصال به بایننس و ال‌بانک، و راه‌اندازی سرویس `telec-data`.

برای هشدار تلگرام، `ADMIN_BOT_TOKEN` و `ADMIN_CHAT_ID` را در `/opt/telec-signal/.env` بنویسید و سرویس را ری‌استارت کنید:

```bash
sudo systemctl restart telec-data
```

## دستورهای کاربردی

```bash
journalctl -u telec-data -f                                  # لاگ زنده
sudo systemctl status telec-data                             # وضعیت
cd /opt/telec-signal && .venv/bin/python scripts/check_connectivity.py   # تست اتصال
sudo git pull && sudo bash deploy/install.sh                 # به‌روزرسانی
```

بررسی داده در دیتابیس:

```bash
sudo -u postgres psql telec_signal -c "SELECT symbol, tf, count(*), max(open_time) FROM candles GROUP BY 1,2 ORDER BY 1,2 LIMIT 20;"
sudo -u postgres psql telec_signal -c "SELECT ts, symbol, tf, kind, detail FROM data_issues ORDER BY ts DESC LIMIT 20;"
```

## GitHub Runner (اختیاری، توصیه‌شده)

با نصب Runner روی همین سرور، با هر تغییر کد تست‌ها و اتصال واقعی به صرافی‌ها خودکار اجرا می‌شود.
در گیت‌هاب: Settings → Actions → Runners → New self-hosted runner → Linux، و دستورهایی که نشان می‌دهد را در `/opt/actions-runner` اجرا کنید (کاربر غیر root). سپس:

```bash
sudo ./svc.sh install && sudo ./svc.sh start
```
